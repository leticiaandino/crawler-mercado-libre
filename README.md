# Crawler Mercado Libre

Un crawler para extraer información de productos de MercadoLibre.

## Descripción

Este proyecto es una aplicación Spring Boot que permite realizar web scraping de productos en MercadoLibre para obtener información relevante como precios, descripciones y características.

## Tecnologías

- Java
- Spring Boot
- Maven

## Instalación

1. Clona el repositorio
2. Ejecuta `mvn clean install`
3. Ejecuta `mvn spring-boot:run`

## Uso

La aplicación se ejecuta en el puerto por defecto de Spring Boot (8080).
